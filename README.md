# Lab4-MariaAchkar

Lab 4 - Git and GitHub Project

## Project Description
This project contains two implementations of a School Management System:
- A Tkinter interface
- A PyQt5 interface

## Files
- `part2_tkinter.py` - Tkinter implementation
- `part3_pyqt5.py` - PyQt5 implementation

## How to Run

### Tkinter
Run:
python part2_tkinter.py

### PyQt5
Run:
python part3_pyqt5.py

## Tkinter and PyQt
Tkinter is used to create one graphical user interface for the School Management System.

PyQt5 is used to create another graphical user interface for the same system using the PyQt5 framework.
